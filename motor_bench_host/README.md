# 电机测试台上位机

配套固件:[`motorbench-a`](../motorbench-a)(A 板 + USB CDC，CMake 主工程)。
另有 [`motorbench-c`](../motorbench-c) 的 C 板阶段性快照（固件 1.6，仅 USB），共用本上位机。
固件回归默认读取 A 板目录；验证 C 板时，在 PowerShell 中设置
`$env:MOTORBENCH_FIRMWARE = 'motorbench-c'`，再执行 `npm test`、
`npm run test:integration`、`npm run test:motor-state`。
完成后用 `Remove-Item Env:MOTORBENCH_FIRMWARE` 恢复默认。该变量仅影响测试，不影响服务运行。

## 快速开始

```bash
npm install          # 安装 serialport 与 ws
npm start            # 启动后访问 http://localhost:8080
```

修改 `server.js` 或后台使用的 `protocol.js` 后需重启对应的 Node 服务，再用 `Ctrl+F5` 刷新网页。
仅修改 HTML/CSS/网页脚本时刷新即可；静态文件使用 `Cache-Control: no-store`，页脚标注 `UI 20261018-pid-context` 便于核对。
本次从旧缓存策略升级时仍需先强制刷新一次，或打开 `http://127.0.0.1:3000/?v=20261018-pid-context`，确认页脚版本与 PID 单位、流程说明已显示。
只刷新网页不会更新后台已加载的代码。网页会检查后台是否支持通道清理；
若提示“后台版本过旧”，需重启后台。清理超时会显示缺少应答的通道，可点击“同步清单”重试。
通道清理按 0～7 逐个发送，收到应答后才发送下一个；单个通道每 400 ms 重试，最多发送 3 次，
避免批量指令跨 USB 包时漏掉最后一个通道。关闭串口会同时取消启动及常规心跳定时器。

命令行参数:

```bash
node server.js --port 8080              # HTTP 端口
node server.js --serial COM5 --baud 115200
node server.js --host 0.0.0.0           # 允许同一局域网的手机/平板访问(谨慎)
```

## 使用流程(USB 直连,推荐)

1. 用**一根普通 USB 线**把 A 板插到电脑(板载 Micro USB-OTG FS,接口编号 17)
   —— 不需要外接 USB 转串口模块
2. 上电烧录好电机测试台固件
3. Windows 设备管理器会出现一个新的 **COM 口**(产品名 `Motor Bench CDC`)
4. 页面点「刷新」选它 → 「打开」
5. 页面自动拉取固件登记的电机清单并填入下拉框
6. 选电机 → 「绑定」→ 拖滑块设转速 → 「使能」
7. 结束务必「停机」或直接点顶部「急停」；页面处于焦点时也可按空格立即全停

测试通道卡片数量与板端登记的电机数量一致：添加一颗增加一张，删除后回收多余卡片，没有电机时不显示空通道。
删除优先移除对应电机的卡片或未使用卡片；其余卡片的绑定、目标、PID、曲线和计算器参数保持。
板端通道号保留，删除中间卡片后编号可以不连续，后续添加时复用空闲编号，避免改动正在运行的通道。
左侧「计算」入口打开当前第一个通道；没有电机时需先添加电机。
固件 1.4 补齐电机销毁时的通道、驱动、守护和 CAN 过滤器回收；使用动态删除请同步烧录新固件。

> **波特率随便填**:USB CDC 是包协议,不依赖真实波特率,
> `Motor Bench CDC` 的枚举名比普通 UART 好认。

曲线按型号显示单位：DM4310 / DM8009P 为转速 `rad/s`、转矩 `N·m`，对应当前 MIT 驱动的反馈量；
大疆电机为转速 `rpm`、电流协议原始值 `raw`，未换算为安培。
鼠标悬停曲线可查看最近一次遥测的数值（曲线本身仍按所选滤波设置绘制）。
未使能时仍显示真实反馈；DM 速度轴最小跨度为 1 rad/s，刻度保留小数，避免放大零速附近的量化波动。

### PID 参数规划（A 板固件 1.10）

默认值分型号、分闭环，网页恢复默认与固件新建实例使用同一组基线；保留用户主动调过的在线参数。

| 型号 / 环 | Kp | Ki | Kd | 输出限幅 | 积分限幅 |
| --- | ---: | ---: | ---: | --- | ---: |
| DM4310 速度环 | 0.65 | 12 | 0 | 15 N·m | 1000 |
| DM8009P 速度环 | 0.05 | 0 | 0 | 10 N·m | 0 |
| 两款 DM 位置环 | 0.1 | 0 | 0 | 2 rad/s | 0 |

4310 速度环五参数按用户指定设置，积分限幅保持开启；最终转矩指令仍受 15 N·m 输出限幅约束。8009P 基线来自用户确认可驱动、板端读回的参数；位置环保持原起点。两款 DM 的电流环由电调内部执行，网页不可整定；DJI 各型号已有参数保持，不使用 DM 的转矩参数。

整定顺序：先确认量纲和输出上限足以起转 → 仅调速度 Kp → 有稳态误差再逐步增加 Ki、设置非零积分限幅 → 速度稳定后调位置 Kp 与最大追踪速度。Kd 默认保持 0。
例如 Kp=0.05、误差 30 rad/s，比例转矩为 1.5 N·m；MaxOut=0.5 会截断，改到 10 只解除这个瓶颈，不会强制输出 10。Ki=0 时积分限幅不起作用；Ki>0 且积分限幅=0 时也无法保留积分补偿。工作限幅需结合实际负载整定，协议 TMAX 54 不是建议工作转矩。

刷新到 `UI 20261018-pid-context` 后，“恢复默认值”只填表并请求停机归零，点击“应用到电机”才写入并零目标使能。1.10 固件保证重建电机时也得到同样默认值。不会自动改写目前在线电机；Node 无需重启。

### 电机离线自动重连（A 板固件 1.8）

电机断电或断开 CAN 后，通道显示“离线 · 自动重连中”。接回后恢复反馈和原绑定，目标归零，点击使能再运行；自动输出和 PID 应用后的自动使能会在离线时取消，不自动续跑。DJI 使用主动反馈，DM4310/DM8009P 使用无需使能的定期查询。此功能需要主板及 USB 会话保持；页面刷新仍清空测试通道。

烧录 `motorbench-a` 固件 1.8，刷新后确认页脚 `UI 20261018-pid-context`。本次未修改 Node 服务逻辑，无需为此重启 Node。

### DM8009P（A 板固件 1.7）

- 新增独立的 `DM8009P` 选项，协议型号为 7；DM4310 保持型号 4。
- 依据本次从用户电机读回的参数：MIT 模式，PMAX=12.5、VMAX=45、TMAX=54。
  DM4310 保持 TMAX=18；每颗电机独立保存量程，可同时添加。本配置不修改电调参数。
- TX / RX 均使用带 `0x` 前缀的十六进制输入。截图中 CAN ID=0x01 对应 TX 输入 `01`，
  Master ID=0x11 对应 RX 输入 `11`；CAN 总线按实际接线选择。
- 速度单位 rad/s，转矩反馈及速度 PID 输出单位 N·m；54 是协议量程上界，不是建议工作转矩。
  从固件 1.9 起默认速度输出限幅为 10 N·m，采用用户确认可驱动的起点，仍需按实际负载整定。
- 支持速度／位置串级、PID 读写、自动输出、计算器和动态删除；电流环由电调内部控制。
- 需烧录 `motorbench-a` 固件 1.7；旧固件会在添加前明确提示升级。
  `motorbench-c` 保持独立的 1.6 阶段性快照，本次未同步。
- 型号及量程适配不代表已解决当前离线问题；仍需验证 CAN1 的实际反馈报文。

### 闭环切换与 PID 整定（固件 1.6）

烧录 1.6 固件、重启 Node 后台，再用 `Ctrl+F5` 刷新页面。绑定后可直接点击鱼骨图切换速度／位置闭环，
无需解绑。切换会停止本通道及其自动输出，清零目标与 PID 控制历史，保留绑定和已整定参数；
收到板端应答后才更新目标单位、清空曲线，并读回当前 PID。切换后需手动重新使能，其它通道保持原状。
切换超时会锁定本通道控制，提示解绑重试或重连；旧固件或旧后台不开放绑定后的切换。
DM4310 必须保留速度环，支持速度控制与位置＋速度串级之间切换。
固件 1.6 修正心跳应答的负载长度：实际 8 字节，此前误标 9 字节导致后台丢弃心跳，
网页即使收到遥测也无法确认固件版本，绑定后的闭环按钮一直锁定。闭环配置现在直接显示锁定原因。

闭环节点左键开关该环，右键选择对应 PID，标题显示当前整定环；悬停和聚焦不切换参数，不再提供环选择下拉框。
电流环继续常开，DJI 可右键整定电流 PID，DM 的电流环由电调内部执行。位置环仍自动联动速度环。
绑定后可反复修改参数并点击「应用到电机」，
无需解绑。修改任一 PID 参数或恢复默认值时，立即请求本通道停机、清零目标并取消自动输出；其它通道继续运行。
点击“应用到电机”后，等待板端成功回执，再自动以零目标使能；不会恢复此前的非零目标或自动输出预设。
应用失败则保持停机；2 秒未收到确认时保持停机并锁定再次应用，等待回执或解绑重连，避免把迟到回执当成新请求。
等待期间若急停、手动停机、再次修改参数、切换闭环、解绑、删除电机、断连或转入后台，取消本次自动使能。
这里“归零”指目标值清零，不驱动电机回原点；位置模式在自动重新使能时，按既有规则将当前位置定义为新 0°。
悬停任一环不会覆盖正在填写的参数。

### 位置控制

每次由停机切换到使能时，当前位置定义为 **0°**，此前速度测试累计的圈数不会作为位置目标。
默认目标为零时保持本次使能位置；输入 `30` 表示相对本次零点正向 30°，输入 `-30` 表示反向 30°。
若使能前已填写非零目标，确认后会按新零点执行该目标。重复使能指令不重置零点，反馈离线时拒绝位置环使能。
目标输入及曲线均为 `deg`，限幅 ±360°；曲线展示相对零点的位置和目标，悬停仍可查看实际转速。
「归零」将目标设为本次使能的 0°，不重新定义零点。

M2006/M3508 使用电机转子编码器角度，**没有按减速比换算输出轴角度**。DM4310 使用现有 MIT 位置反馈范围，
目标还会受其绝对位置量程限制。位置模式仍可切换到「自动输出」查看面板，面板以阴影遮罩提示当前处于位置环，
正弦、阶梯转速预设暂不可用；关闭位置环、保留速度环后遮罩自动消失，重新使能即可启动预设。

M2006/M3508 默认位置 Kp=4，输出限幅 600 deg/s；DM4310 默认位置 Kp=0.1，输出限幅 2 rad/s，
位置 PID 的输出作为速度 PID 的目标。以上参数仅为初始整定值，仍需按实物负载验证。
DM4310 支持位置、速度 PID 设置和读回，限幅支持 0.001 精度；单独电流 PID 不开放。
DM4310 速度环的输出／积分限幅单位为 N·m，位置环为 rad/s；网页标注单位并在下发前校验输出限幅。
当前驱动配置的 MIT 协议上限分别为 18 N·m、45 rad/s，这些是编码范围，**不是建议工作值或额定能力**。
例如速度环输出限幅填 200 表示 200 N·m，会被拒绝；旧固件误报“不支持”，新版网页也会提示检查 PID 环及限幅范围。
DM4310 “恢复默认值”：速度 Kp=0.65、Ki=12、Kd=0、输出限幅 15 N·m、积分限幅 1000（固件 1.10）。DM8009P 使用本页参数表的独立限幅。

### 计算器

各通道目标设定下方提供「自动输出 / 计算器」并列页签，计算器类型当前提供「射频 → 转速」，后续可继续扩展。
左侧「计算」入口打开当前第一个通道的计算器。流程为：射频 → 拨盘每圈发数 → 传动方式 → 电机转速。
最后的电机转速节点提供「+ 正值 / − 负值」切换按钮，默认正值；各通道独立，rpm 与 rad/s 同步切换符号，拨盘计算值不变。切换后按现有规则自动填入上方目标框，不立即下发；正负方向均执行转速限幅检查。
每行最多并列两个通道，窄屏改为单列。计算器按通道宽度自动采用横向四步、两行折返或纵向四步，完整展示流程，无需横向滑动。
每圈发数留空，由用户按实际拨盘填写；传动方式可选「直驱」（比值固定为 1）或「减速传动」（自行填写总减速比）。
实时得到电机转子 rpm、rad/s 及拨盘输出 rpm。每个通道独立保存本页计算参数。
修改计算参数或打开计算器页签时，有效结果自动填入本通道上方目标框及滑块；DJI 写入 rpm，DM4310 写入 rad/s。
自动填框不发送控制指令：按目标框 Enter 下发；尚未使能时，点击使能会执行框中的目标（非零目标沿用原确认）。
位置/单独电流模式、未选电机、自动输出运行中或计算结果超出该型号限幅时，仅显示结果并说明未写入原因。
停机、归零、解绑和网页重置不会因保留的计算参数而自动恢复旧目标；重新修改参数或打开计算器后才填入。

换算参考旧工程 `application/shoot/shoot.c` 的连发公式：
`转子 rpm = 射频 × 60 × 总减速比 / 每圈发数`。旧驱动使用 deg/s，网页 DJI 速度目标使用 rpm，不能直接照抄旧公式的数值。
例如射频 8 发/秒、每圈 8 发时，直驱为 60 rpm，减速比 36 时为 2160 rpm。
旧运行公式按每圈 8 发，`robot_def.h` 中 `NUM_PER_CIRCLE` 却为 10，因此计算器不预设每圈发数。
M3508 减速比参考 19，DM4310 直驱为 1；额外传动比应计入总减速比。
结果是理论目标转速，实际速度由反馈确认。反转时可手动填写负目标；
该计算器用于拨弹射频换算，不用于摩擦轮弹丸线速度计算。刷新网页即可使用，无需烧录。

### 自动转速输出

每个通道的「目标设定」下方提供独立的自动输出，先绑定速度环电机并使能，再点击「启动预设」。

- **正弦输出**：目标 = 偏置 + 幅值 × sin(2πt / 周期)，可设置循环次数；默认幅值 500 rpm、偏置 0、周期 4 秒、运行 1 轮。DM4310 默认幅值为 1 rad/s。
- **阶梯输出**：按目标序列逐级保持，例如 `0, 500, 1000, 500, 0`，设置每级保持时间和循环次数；支持负数、小数及中文逗号，DM4310 序列按 rad/s 填写。

正弦目标由网页每 50 ms 更新一次，阶梯目标在切级时下发；实际目标仍由板端遥测回传到曲线。
正弦周期最短 0.5 秒，阶梯每级最短 0.1 秒；循环次数为 1～1000，目标必须在当前型号的限幅内，超限会拒绝启动。
运行期间锁定手动输入，完成或点击「停止并归零」时下发零目标，电机仍保持使能。
归零、停机、急停、解绑、通道重置或断连均取消自动输出；页面转入后台、反馈超过 500 ms 未更新或调度间隔超过 250 ms 时中止输出并请求停机，恢复后需手动重新启动。
自动输出仅用于速度环，位置环和单独电流环通道不提供启动入口。功能由网页实现，更新后 `Ctrl+F5` 刷新即可，无需重新烧录。

### 如果改用 UART 通道

把固件 `application/robot_def.h` 里的宏换成:

```c
// #define MOTOR_BENCH_LINK_USB
#define MOTOR_BENCH_LINK_UART
```

重新编译烧录,然后用 USB 转串口线接 A 板 UART7(PE7/PE8,3.3V,交叉接+共地),
上位机操作完全不变。

## 安全设计(重要)

| 机制 | 说明 |
| --- | --- |
| 上电默认停止 | 所有电机登记后即为 `MOTOR_STOP`,必须显式「使能」才输出 |
| 未使能拒写参考值 | 通道未使能时板端拒绝写入并打日志 |
| 参考值限幅 | 固件侧硬限幅 ±12000,防止误输入打飞电机 |
| 心跳看门狗 | 上位机 200ms 一跳;约 1s 收不到,A 板自动全停 |
| 握手门闩 | 链路未建立时,除心跳/查询外的指令一律丢弃 |
| 急停 | 页面「急停」、空格快捷键、页面关闭、服务 Ctrl+C 退出都会下发全停 |
| USB 不阻塞 | 固件发送队列满时丢弃帧,不阻塞 500Hz 电机控制任务 |

空格快捷键在本页面获得键盘焦点时有效，输入框内同样触发；长按只触发一次，不会触发当前聚焦按钮或恢复使能，同时取消所有通道的自动输出。切到其他应用、浏览器地址栏或其他标签页时无法接收该快捷键。

**物理急停按钮建议单独加一个**(框架 TODO 里也提到"急需一个无线遥控继电器")。
软件链路再可靠,也不该作为唯一的停机手段。

## 自测

```bash
npm test                  # 协议自测(45 项),不依赖串口
npm run test:integration  # 把固件 crc8.c 编译成原生程序,与 Node 侧逐位比对
npm run test:motor-state  # 实际 C 驱动的启停、位置级联、零点及 DM 小数 PID 回归
npm run test:setpoint     # 正弦、阶梯时序、循环边界和参数校验
npm run test:calculator   # 射频换算、原公式单位对齐及输入校验
node txqueue_test.js      # USB 发送环形队列模型测试
```

`test:integration` 需要本机有 gcc/clang(MinGW 亦可)。它把固件
`modules/algorithm/crc8.c` 原样编译成命令行程序,喂同一批字节给固件算法和
Node 实现 —— 比"两边各写一遍 CRC 再对答案"可靠得多。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `protocol.js` | 帧组装/解析/CRC,必须与固件 `motor_bench.h` 保持一致 |
| `server.js` | 串口 ↔ WebSocket 桥,附带心跳、全停、退出清理 |
| `ui.js` / `index.html` / `style.css` | 浏览器界面 |
| `selftest.js` | 协议自测 |
| `integration_test.js` | 与固件 CRC 的交叉校验 |
| `txqueue_test.js` | USB 发送队列行为模型 |

## 换串口

固件默认 USB;若要换 UART,改
`application/motor_bench_app/motor_bench_app.c` 里的
`MotorBenchInit(&huart7)`。该串口必须已在 CubeMX 中开启 RX DMA
(A 板上 UART7/UART8 的 DMA 中断均已在 `stm32f4xx_it.c` 中使能)。
