# 电机测试台上位机

配套固件：[`motorbench-a`](../motorbench-a)（A 板）、[`motorbench-c`](../motorbench-c)（C 板）、[`motorbench-mc02`](../motorbench-mc02)（MC02），共用本上位机。三套工程已对齐到 1.26，MC02 待实机验证。
三套工程的控制功能已对齐，硬件配置分别保留，见 [完整对照](../docs/FIRMWARE_PARITY.md)。

固件 1.24 在心跳中上报板型，网页显示“A 板在线”“C 板在线”或“MC02 板在线”；旧固件没有板型信息，显示通用“控制板在线”。不根据 COM 编号或固件版本猜测板型。如果页面仍固定显示旧的“A 板在线”，使用 `Ctrl+F5` 强制刷新。
三板的单发/双发、位置角度、速度过渡和默认参数保持一致；引脚、时钟及 USB 等板级配置分别保留。
固件回归默认读取 A 板目录；验证 C 板或 MC02 时，在 PowerShell 中设置
`$env:MOTORBENCH_FIRMWARE = 'motorbench-c' # MC02 改为 motorbench-mc02`，再执行 `npm test`、
`npm run test:integration`、`npm run test:motor-state`。
完成后用 `Remove-Item Env:MOTORBENCH_FIRMWARE` 恢复默认。该变量仅影响测试，不影响服务运行。

## 快速开始

### Windows 桌面便携版

发布文件为 `dist/MotorBench-1.2.0-Windows-x64.exe`（Windows 10/11，64 位）。
也可从 [GitHub Releases](https://github.com/wbz2006/RM-MotorBench/releases/tag/host-v1.2.0) 下载。
直接双击进入独立的电机调试窗口，无需安装 Node.js，也不用另外打开浏览器。
EXE 内置 Electron、网页界面及串口依赖，可离线使用；电机控制仍需连接主板。
关闭窗口时，后台先请求电机全停并关闭串口，再退出。重复启动会激活已有窗口。
本地服务仅监听 `127.0.0.1`，自动选择空闲端口，不占用固定的 3000 端口。
日志在 `%APPDATA%/motor-bench-host/desktop.log`。

开发、重新打包（需 Node.js 22.12 以上与 npm，首次下载打包工具需要联网）：

```powershell
cd motor_bench_host
npm ci
npm run desktop       # 开发模式，独立窗口
npm run build:exe     # 生成 dist 下的单文件便携版
npm run test:desktop  # 检查打包后的窗口、资源、串口枚举与退出
```

对外分发 `MotorBench-1.2.0-Windows-x64.exe` 即可。便携 EXE 会在启动时将运行文件
解压到临时目录，因此首次启动比后续启动慢。当前发布包未做代码签名。

### 浏览器开发模式

```bash
npm install          # 安装 serialport 与 ws
npm start            # 启动后访问 http://127.0.0.1:3000
```

修改 `server.js` 或后台使用的 `protocol.js` 后需重启对应的 Node 服务，再用 `Ctrl+F5` 刷新网页。
仅修改 HTML/CSS/网页脚本时刷新即可；静态文件使用 `Cache-Control: no-store`，页脚标注 `UI 20261024-loader-control` 便于核对。
若浏览器仍有旧缓存，先强制刷新一次，或打开 `http://127.0.0.1:3000/?v=20261024-loader-control`，确认页脚版本已更新。标题使用多开发板标识，顶部红色“全部急停”按钮突出显示“空格 / SPACE”快捷键，窄屏下同样可见。
只刷新网页不会更新后台已加载的代码。网页会检查后台是否支持通道清理；
若提示“后台版本过旧”，需重启后台。清理超时会显示缺少应答的通道，可点击“同步清单”重试。
通道清理按 0～7 逐个发送，收到应答后才发送下一个；单个通道每 400 ms 重试，最多发送 3 次，
避免批量指令跨 USB 包时漏掉最后一个通道。关闭串口会同时取消启动及常规心跳定时器。

命令行参数:

```bash
node server.js --port 8080              # HTTP 端口
node server.js --serial COM5 --baud 115200
node server.js --host 0.0.0.0           # 允许同一局域网的手机/平板访问(谨慎)
```

## 使用流程(USB 直连,推荐)

串口选择区保留可展开的“如何选择正确的串口？”教程：右键点击 Windows“开始”图标 → 设备管理器 → 端口（COM 和 LPT），插拔控制板 USB 数据线，记下随插拔消失、出现的 COM 编号；回到网页点击“刷新”，选择同一编号并连接。

### 曲线交点读数

鼠标移入曲线绘图区后，橙色竖线随鼠标左右移动，交点标记与浮层分别显示实测转速（位置模式为角度）、反馈和设定值，各自保留对应单位。读数根据当前显示的曲线线段插值，开启滤波时与滤波后的曲线一致；实时数据更新时读数同步变化。移出绘图区或清空曲线后隐藏读数，尚无曲线的空白区域不显示数值。

可用 `npm run test:chart` 在隐藏的 Electron 窗口中验证游标、交点读数及边界行为，不连接控制板。

### 单发 / 双发位置测试（UI 20261024-loader-control，固件 A / C 1.25）

需配套新版 Node 服务与固件；网页按服务能力和心跳 `0x80` 检查支持，旧固件仍可进行其他测试。更新服务后刷新页面；固件需另行烧录。

绑定电机后打开「计算器 → 单发 / 双发位置测试」，填写拨盘每圈发数、传动方式、单发/双发和转向。所有参数输入采用统一标题高度，动态数值使用固定网格，数值位数变化不会挤动触发区。

M2006、M3508 默认不计入内置减速比，本区目标、实测、误差均显示转子角度。小复选框「计入电机内置减速箱」勾选后，才乘以 M2006 的 36 或 M3508 的 19；外部传动另填。
以 8 发/圈、外部直连为例：不勾选时单/双发为转子 45° / 90°；M2006 勾选后为转子 1620° / 3240°，对应输出轴 45° / 90°。本区将转子目标和反馈换算为协议输出轴度，其他通道显示和普通位置控制仍使用输出轴单位。

上方按钮依次提供「切换为位置环」「使能位置环 · 当前位置置零」「开始测试 · 锁定角度目标」。测试后滑块、角度输入、归零和参数锁定，固定区域左键按下一次执行一组，长按不重复，运动中点击不排队。

到位容差默认本次步进的 5%，可设 0.1～10%。该容差随请求送入固件，网页连续两帧进入容差后完成计数，固件用上一组的同一容差允许下一组。DJI 进入容差后位置环输出为零，速度环继续制动；超出容差仍可纠偏。下一次目标从原理论目标累计，避免每发的剩余误差逐次累积；普通手动位置控制不启用此死区。
「指令发数」在成功回执后增加，「到位发数」在遥测达到容差后增加；这是位置动作计数，不是实际出弹检测。

退出、失焦、后台或遥测超时 500ms 时退出测试并停机；回执超时 1.5s、动作超时 60s 同样停机，空格始终急停。不会因超时强行判定到位，也不会自动重发。

位置步进 `0x0E` 原 7 字节请求为通道 u8、请求号 u16、步进 float；1.25 另接受 11 字节请求，追加容差 float，所有角度均为输出轴度、小端。回执 `0x8F` 保持 8 字节：通道 u8、请求号 u16、结果 u8、目标 float。旧请求保留原行为。
每组输出轴步进为 0.001～36000°，累计相对本次使能零点的输出轴目标限制 ±1000000°，DM 另受实际绝对位置量程限制；历史原始转子圈数不会导致新零点下的合法目标误拒绝。普通手动位置目标仍限 ±360°。

运行 `npm run test:loader` 验证实际浏览器交互、M2006/M3508 两种复选框状态与 1440/860/390/320px 动态布局；`npm run test:motor-state` 验证实际控制代码、共享容差、累计目标和死区恢复。通过 `MOTORBENCH_FIRMWARE` 分别选择 A/C；两套 Debug/Release 均已构建，尚未进行本次实机烧录验证。

### 页面引导

顶部按「连接控制板 → 添加电机 → 绑定通道 → 使能并测试」显示当前步骤和下一步入口，
以板端清单、通道遥测和使能反馈确认进度。引导按钮只定位操作区域，不会启动电机。

「第一次测试怎么做？」和闭环配置中的帮助可按需展开，包含登记与绑定、TX/RX、PID 应用和位置归零说明。

确认页脚版本为 `UI 20261024-loader-control`。可用 `npm run test:guidance` 在隐藏的 Electron 窗口中验证模拟控制板流程及窄屏布局，不会访问实际串口。

### 接入与测试

1. 用**一根普通 USB 线**把 A 板插到电脑(板载 Micro USB-OTG FS,接口编号 17)
   —— 不需要外接 USB 转串口模块
2. 上电烧录好电机测试台固件
3. Windows 设备管理器会出现一个新的 **COM 口**(产品名 `Motor Bench CDC`)
4. 页面点「刷新」选它 → 「打开」
5. 页面自动拉取固件登记的电机清单并填入下拉框
6. 选电机 → 「绑定」→ 拖滑块设转速 → 「使能」
7. 结束务必「停机」或直接点顶部「急停」；页面处于焦点时也可按空格立即全停

测试通道卡片数量与板端登记的电机数量一致：添加一颗增加一张，删除后回收多余卡片，没有电机时不显示空通道。
删除优先移除对应电机的卡片或未使用卡片；其余卡片的绑定、目标、PID、曲线和计算器参数保持。
板端通道号保留，删除中间卡片后编号可以不连续，后续添加时复用空闲编号，避免改动正在运行的通道。
左侧「计算」入口打开当前第一个通道；没有电机时需先添加电机。
固件 1.4 补齐电机销毁时的通道、驱动、守护和 CAN 过滤器回收；使用动态删除请同步烧录新固件。

> **波特率随便填**:USB CDC 是包协议,不依赖真实波特率,
> `Motor Bench CDC` 的枚举名比普通 UART 好认。

曲线按型号显示单位：DM4310 / DM8009P 为转速 `rad/s`、转矩 `N·m`，对应当前 MIT 驱动的反馈量；
大疆电机为转速 `rpm`、电流协议原始值 `raw`，未换算为安培。
鼠标悬停曲线可查看最近一次遥测的数值（曲线本身仍按所选滤波设置绘制）。
未使能时仍显示真实反馈；DM 速度轴最小跨度为 1 rad/s，刻度保留小数，避免放大零速附近的量化波动。

### 通用速度过渡与快速归零（A 板 1.18 起，A/C 1.23 对齐）

A、C、MC02 当前固件均支持下述功能，心跳 `board_flags` bit4（`0x10`）明确表示支持速度过渡及快速归零。
网页按该能力位显示按钮，兼容此前 A 板版本；切换固件或断开连接时会刷新、清除能力状态。

所有已接入电机的速度模式统一使用黄色“快速归零”：保持使能，快速制动到目标 0；
输入 0 和自动输出到 0 同样适用。普通变速及跨正负反向连续过零，保持已有积分补偿。
红色停机/急停直接停机，清除过渡状态；位置、电流和开环模式保持普通“归零”语义。

| 电机 | 普通变速/反向 | 快速归零 |
| --- | ---: | ---: |
| DM4310 / DM8009P / LK9025 / HT04 | 100 rad/s² | 200 rad/s² |
| GM6020 / M3508 / M2006 | 30,000 rpm/s | 60,000 rpm/s |

这些是内部目标变化率，实际机械响应按负载复验。速率由固件 `motor_bench.h` 的
`MB_SPEED_ACCEL_RAD/RPM`、`MB_SPEED_ZERO_DECEL_RAD/RPM` 配置；普通速率设为 0 绕过过渡。
HT04 下发速度同步补齐 rad/s→内部 deg/s 的换算；LK9025 速度计算改用速度 PID 和速度反馈源。
旧 A 板固件仍按版本显示实际能力：1.17 仅 4310 使用快速归零，1.16 为旧 10 rad/s² 过渡；旧 C 板 1.16 及之前未同步这套速度过渡，应升级至 1.23。

1.18 已通过 J-Link 烧录及完整读回校验；COM17 确认版本，当前两台 DM 的登记、通道与 PID
均已恢复并读回一致，保持停机、目标 0，未实机使能验证运动。
上述为 A 板 1.18 的历史验证记录；当时 C 板快照未同步，此差异现已在 A/C 1.23 中补齐。网页当前版本为 `UI 20261024-loader-control`，本次步进容差协议需要重启 Node 服务。

### DM4310 实际量程与默认 PID（A 板固件 1.18）

默认值分型号、分闭环，网页恢复默认与固件新建实例使用同一组基线；保留用户主动调过的在线参数。

| 型号 / 环 | Kp | Ki | Kd | 输出限幅 | 积分限幅 |
| --- | ---: | ---: | ---: | --- | ---: |
| DM4310 速度环 | 0.55 | 0.5 | 0 | 7 N·m | 100 |
| DM8009P 速度环 | 0.55 | 5 | 0 | 17.5 N·m | 100 |
| 两款 DM 位置环 | 0.1 | 0 | 0 | 2 rad/s | 0 |

1.17 将 DM4310 速度模式的普通变速及跨正负反向变化率提高为 **100 rad/s²**，
0→20.94 rad/s 的内部目标过渡约 0.21 秒。最终目标为 0 时，采用 **200 rad/s²**
快速制动（从上限到零约 0.105 秒的内部参考过渡），保留使能及已有积分补偿；
手动输入 0、黄色“快速归零”按钮及自动输出到 0 均适用。非零反向目标经过零速仍用普通变化率。
红色停机/急停立即撤销使能；位置模式保留原“归零”语义。实际机械响应及停止时间需按负载复验。
途中改目标继续当前参考，手动、使能预填和自动输出均适用，短周期波形可能无法达到最终目标。
曲线虚线仍表示最终目标。1.18 的 8009P 速度模式同样经过此过渡；位置串级不经过，PID 参数沿用上表。
1.18 将逻辑推广至所有已接入电机，配置常量统一为 `MB_SPEED_ACCEL_RAD/RPM`、`MB_SPEED_ZERO_DECEL_RAD/RPM`，
网页目前不提供运行期编辑；原始阶跃整定可将前者设为 0 后重新构建烧录。

DM-J4310-2EC V1.1 按调试助手实际读回使用 PMAX=12.5、VMAX=30、TMAX=10；8009P 保持独立的 12.5/45/54。控制编码、反馈解码按各自量程执行，不修改电调内的配置；网页工作转速限幅另按供电规格设置。

DM8009P 当前按 24 V 供电设置速度目标上限为 **±17.6 rad/s**：官方 DM-J8009P-2EC 说明书 V1.3 第 7 页给出最大空载转速 168 rpm（约 17.59 rad/s）。滑块、数字输入下发及使能预填目标均限幅，自动预设和计算器拒绝超限值；位置目标仍为 ±360°，MIT 编解码范围保持 12.5/45/54。该上限是空载规格，带载可达转速更低；48 V 对应 335 rpm（约 35.1 rad/s），当前程序未启用该供电档位。

位置环的输入为角度（deg），输出为目标速度（DM 使用 rad/s），因此输出限幅表示最大追踪速度。DM8009P 网页位置环输出限幅统一校验为 **0～17.6 rad/s**，DM4310 网页及板端校验为 **0～20.94 rad/s**，与各自 24 V 速度模式共用上限；积分项也采用速度单位。超过上限时拒绝下发，默认输出限幅仍为 2 rad/s。

4310 手册额定电压 24 V、减速比 10:1，额定转矩 3 N·m、峰值 7 N·m，额定转速 120 rpm（12.57 rad/s）、空载最高 200 rpm（20.94 rad/s）。按用户截图，默认工作限幅取 7 N·m；网页和固件拒绝超过 7 N·m 的工作限幅，驱动最终转矩也受峰值约束。7 N·m 不代表可持续输出，TMAX=10 仅是协议映射范围。1.17 将工作速度目标上限统一为 **±20.94 rad/s**：滑块、数字下发、使能预填及板端速度目标均限幅，自动预设和计算器拒绝超限，MIT 协议 VMAX=30 保持原值。带载可达速度更低。

旧量程 45/18 会把速度显示放大 1.5 倍、反馈转矩放大 1.8 倍；原显示 30 rad/s 实际约为 20 rad/s。升级后目标和反馈均使用正确单位，不能继续沿用旧目标数值。1.15 按用户要求更新上表两款速度环默认值；两者积分限幅功能开启，位置环和 DJI 参数沿用原值。两款 DM 的电流环由电调内部执行，网页不可整定。

整定顺序：先确认量纲和输出上限足以起转 → 仅调速度 Kp → 有稳态误差再逐步增加 Ki、设置非零积分限幅 → 速度稳定后调位置 Kp 与最大追踪速度。Kd 默认保持 0。

A 板固件 **1.14** 保留 DM8009P / DM4310 的零速量化区间积分抑制：仅在速度目标为 0 且反馈落在两个最接近零的量化码时冻结积分增量，保留已有保持转矩；非零目标及超出该范围的反馈正常积分。原始曲线仍可能显示约 −0.011 rad/s（8009P）的零速量化值，这不会持续积累转矩。1.14 同时修复 dt=0 时 Kd=0 仍产生 NaN 的路径，增加异常计时/非有限控制值停机保护及 DWT 计时使能恢复；异常后不会自动重新使能。实际失控瞬间的 dt 尚未捕获，未做实机使能验证。需要烧录新固件，刷新网页无法替代固件更新；重启后的 PID 为默认值。
例如 Kp=0.55、误差 10 rad/s，比例转矩为 5.5 N·m；7 N·m 是上限，不是固定施加的转矩。Ki=0 时积分限幅不起作用；Ki>0 且积分限幅=0 时也无法保留积分补偿。工作限幅需结合实际负载整定。

先停机，烧录 A 板 1.18 固件，再重新连接并刷新到 `UI 20261023-loader-range`；新建实例使用表中默认值。网页“恢复默认值”只填表并请求停机归零，点击“应用到电机”才写入并零目标使能。不要将新网页与旧量程固件混用。Node 无需重启；C 板保持独立阶段性快照。

- 新增独立的 `DM8009P` 选项，协议型号为 7；DM4310 保持型号 4。

### 闭环切换与 PID 整定（固件 1.6）

烧录 1.6 固件、重启 Node 后台，再用 `Ctrl+F5` 刷新页面。绑定后可直接点击鱼骨图切换速度／位置闭环，
无需解绑。切换会停止本通道及其自动输出，清零目标与 PID 控制历史，保留绑定和已整定参数；
收到板端应答后才更新目标单位、清空曲线，并读回当前 PID。切换后需手动重新使能，其它通道保持原状。
切换超时会锁定本通道控制，提示解绑重试或重连；旧固件或旧后台不开放绑定后的切换。
DM4310 必须保留速度环，支持速度控制与位置＋速度串级之间切换。
固件 1.6 修正心跳应答的负载长度：实际 8 字节，此前误标 9 字节导致后台丢弃心跳，
网页即使收到遥测也无法确认固件版本，绑定后的闭环按钮一直锁定。闭环配置现在直接显示锁定原因。

闭环节点左键开关该环，右键选择对应 PID，标题显示当前整定环；悬停和聚焦不切换参数，不再提供环选择下拉框。
电流环继续常开，DJI 可右键整定电流 PID，DM 的电流环由电调内部执行。位置环仍自动联动速度环。
绑定后可反复修改参数并点击「应用到电机」，
无需解绑。修改任一 PID 参数或恢复默认值时，立即请求本通道停机、清零目标并取消自动输出；其它通道继续运行。
点击“应用到电机”后，等待板端成功回执，再自动以零目标使能；不会恢复此前的非零目标或自动输出预设。
应用失败则保持停机；2 秒未收到确认时保持停机并锁定再次应用，等待回执或解绑重连，避免把迟到回执当成新请求。
等待期间若急停、手动停机、再次修改参数、切换闭环、解绑、删除电机、断连或转入后台，取消本次自动使能。
这里“归零”指目标值清零，不驱动电机回原点；位置模式在自动重新使能时，按既有规则将当前位置定义为新 0°。
悬停任一环不会覆盖正在填写的参数。

### 位置控制

每次由停机切换到使能时，当前位置定义为 **0°**，此前速度测试累计的圈数不会作为位置目标。
默认目标为零时保持本次使能位置；输入 `30` 表示相对本次零点正向 30°，输入 `-30` 表示反向 30°。
若使能前已填写非零目标，确认后会按新零点执行该目标。重复使能指令不重置零点，反馈离线时拒绝位置环使能。
目标输入及曲线均为 `deg`，限幅 ±360°；曲线展示相对零点的位置和目标，悬停仍可查看实际转速。
「归零」将目标设为本次使能的 0°，不重新定义零点。

A 板 1.20 / C 板 1.14 起，M2006/M3508 的位置目标和曲线反馈统一为**减速箱输出轴角度**，内置减速比按 36:1 / 19:1 换算。例如 M2006 输入 30°，驱动转子目标增加 1080°，到位反馈显示 30°。
固件保留驱动内部转子角度及原位置 PID 参数，速度模式仍使用转子 rpm；额外外部传动只在拨弹测试参数中设置。旧固件页面会明确标示仍为转子角度，并禁止新版拨弹测试。
DM4310 使用现有 MIT 位置反馈范围，
目标还会受其绝对位置量程限制。位置模式仍可切换到「自动输出」查看面板，面板以阴影遮罩提示当前处于位置环，
正弦、阶梯转速预设暂不可用；关闭位置环、保留速度环后遮罩自动消失，重新使能即可启动预设。

M2006 位置环默认值（固件 1.26）：Kp=4、Ki=5、Kd=0、输出限幅 6000 deg/s、积分限幅 1000 deg/s，与用户实机截图一致；网页初始值及“恢复默认值”同步。新建实例自动采用，现有实例需手动应用或重新创建。
M3508 默认位置 Kp=4、Ki=0、Kd=0，输出限幅 600 deg/s、积分限幅 0；DM4310 默认位置 Kp=0.1，输出限幅 2 rad/s，
位置 PID 的输出作为速度 PID 的目标。以上参数仅为初始整定值，仍需按实物负载验证。
DM4310 支持位置、速度 PID 设置和读回，限幅支持 0.001 精度；单独电流 PID 不开放。
DM4310 速度环的输出／积分限幅单位为 N·m，位置环为 rad/s；网页标注单位并在下发前校验输出限幅。
当前驱动配置的 MIT 协议上限分别为 18 N·m、45 rad/s，这些是编码范围，**不是建议工作值或额定能力**。
例如速度环输出限幅填 200 表示 200 N·m，会被拒绝；旧固件误报“不支持”，新版网页也会提示检查 PID 环及限幅范围。
DM4310 “恢复默认值”：速度 Kp=0.55、Ki=0.5、Kd=0、输出限幅 7 N·m、积分限幅 100（固件 1.15）。DM8009P 使用本页参数表的独立限幅。

### 计算器

各通道目标设定下方提供「自动输出 / 计算器」并列页签，计算器类型当前提供「射频 → 转速」，后续可继续扩展。
左侧「计算」入口打开当前第一个通道的计算器。流程为：射频 → 拨盘每圈发数 → 传动方式 → 电机转速。
最后的电机转速节点提供「+ 正值 / − 负值」切换按钮，默认正值；各通道独立，rpm 与 rad/s 同步切换符号，拨盘计算值不变。切换后按现有规则自动填入上方目标框，不立即下发；正负方向均执行转速限幅检查。
每行最多并列两个通道，窄屏改为单列。计算器按通道宽度自动采用横向四步、两行折返或纵向四步，完整展示流程，无需横向滑动。
每圈发数留空，由用户按实际拨盘填写；传动方式可选「直驱」（比值固定为 1）或「减速传动」（自行填写总减速比）。
实时得到电机转子 rpm、rad/s 及拨盘输出 rpm。每个通道独立保存本页计算参数。
修改计算参数或打开计算器页签时，有效结果自动填入本通道上方目标框及滑块；DJI 写入 rpm，DM4310 写入 rad/s。
自动填框不发送控制指令：按目标框 Enter 下发；尚未使能时，点击使能会执行框中的目标（非零目标沿用原确认）。
位置/单独电流模式、未选电机、自动输出运行中或计算结果超出该型号限幅时，仅显示结果并说明未写入原因。
停机、归零、解绑和网页重置不会因保留的计算参数而自动恢复旧目标；重新修改参数或打开计算器后才填入。

换算参考旧工程 `application/shoot/shoot.c` 的连发公式：
`转子 rpm = 射频 × 60 × 总减速比 / 每圈发数`。旧驱动使用 deg/s，网页 DJI 速度目标使用 rpm，不能直接照抄旧公式的数值。
例如射频 8 发/秒、每圈 8 发时，直驱为 60 rpm，减速比 36 时为 2160 rpm。
旧运行公式按每圈 8 发，`robot_def.h` 中 `NUM_PER_CIRCLE` 却为 10，因此计算器不预设每圈发数。
M3508 反馈在转子侧，减速比参考 19；DM-J4310-2EC 内置 10:1 减速器，但网页目标是输出轴速度。若拨盘直接接其输出轴，计算器选直驱（比值 1），不要重复乘内部减速比；额外传动另计。
结果是理论目标转速，实际速度由反馈确认。反转时可手动填写负目标；
该计算器用于拨弹射频换算，不用于摩擦轮弹丸线速度计算。刷新网页即可使用，无需烧录。

### 自动转速输出

每个通道的「目标设定」下方提供独立的自动输出，先绑定速度环电机并使能，再点击「启动预设」。

- **正弦输出**：固定图示标注幅值 A 与周期 T，直接在对应位置输入参数，图形不随参数变化。目标 = A × sin(2πt / T)，以零为中心，不提供偏置；默认幅值 500 rpm、周期 4 秒，DM 默认幅值为 1 rad/s。
- **阶梯输出**：固定图示标注 V1～V5 及每级保持时间 Δt，在图下填入目标序列 V1 → Vn，例如 `0, 500, 1000, 500, 0`；支持负数、小数及中文逗号，DM 序列按 rad/s 填写。
- 两种输出默认勾选「无限循环」，直到点击停止或其它停止条件触发；取消勾选可设置 1～1000 轮。

正弦目标由网页每 50 ms 更新一次，阶梯目标在切级时下发；实际目标仍由板端遥测回传到曲线。
正弦周期最短 0.5 秒，阶梯每级最短 0.1 秒；目标必须在当前型号的限幅内，超限会拒绝启动。
运行期间锁定手动输入，完成或点击「停止并归零」时下发零目标，电机仍保持使能。
归零、停机、急停、解绑、通道重置或断连均取消自动输出；页面转入后台、反馈超过 500 ms 未更新或调度间隔超过 250 ms 时中止输出并请求停机，恢复后需手动重新启动。
自动输出仅用于速度环，位置环和单独电流环通道不提供启动入口。功能由网页实现，更新后 `Ctrl+F5` 刷新即可，无需重新烧录。

## 安全设计(重要)

| 机制 | 说明 |
| --- | --- |
| 上电默认停止 | 所有电机登记后即为 `MOTOR_STOP`,必须显式「使能」才输出 |
| 未使能拒写参考值 | 通道未使能时板端拒绝写入并打日志 |
| 参考值限幅 | 固件侧硬限幅 ±12000,防止误输入打飞电机 |
| 心跳看门狗 | 上位机 200ms 一跳;约 1.5s 收不到(板端守护 150 拍 × 10ms),A 板自动全停 |
| 握手门闩 | 链路未建立时,除心跳/查询外的指令一律丢弃 |
| 急停 | 页面「急停」、空格快捷键、页面关闭、服务 Ctrl+C 退出都会下发全停 |
| USB 不阻塞 | 固件发送队列满时丢弃帧,不阻塞 500Hz 电机控制任务 |

空格快捷键在本页面获得键盘焦点时有效，输入框内同样触发；长按只触发一次，不会触发当前聚焦按钮或恢复使能，同时取消所有通道的自动输出。切到其他应用、浏览器地址栏或其他标签页时无法接收该快捷键。

**物理急停按钮建议单独加一个**(框架 TODO 里也提到"急需一个无线遥控继电器")。
软件链路再可靠,也不该作为唯一的停机手段。
