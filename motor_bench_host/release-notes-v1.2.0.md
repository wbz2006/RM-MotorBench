# MotorBench 上位机 v1.2.0

Windows 10/11 x64 单文件便携版，整合多开发板支持、单发/双发拨弹测试和曲线交点读数。下载 `MotorBench-1.2.0-Windows-x64.exe` 后双击即可使用，无需安装 Node.js；使用随附 `SHA256SUMS.txt` 校验文件完整性。

## 本次更新

- 共用一套上位机连接大疆 A 板、C 板及达妙 MC02；新版固件心跳上报实际板型，旧固件显示通用控制板名称。MC02 已完成源码迁移及编译，仍待实机验证。
- 新增单发/双发拨弹位置测试：设置拨盘每圈发数、传动方式与方向，在固定区域点击触发；测试期间锁定普通角度目标，支持超过普通滑块范围的位置步进。
- M2006/M3508 内置减速比通过复选框选择是否计入，拨弹测试明确区分转子角度与输出轴单位；统一参数排列和数值区域尺寸，减少数据变化造成的卡片闪动。
- 配套固件使用共享到位容差、累计理论目标和 DJI 末端死区，减少单发/双发末端反复修正；同步 M2006 位置环默认参数。
- 曲线新增随鼠标移动的橙色竖线、交点标记与数值读数。
- 增加 Windows 设备管理器串口选择教程，突出空格急停，简化页脚并保留界面版本号。
- 恢复快速归零，完善测试引导；桌面包包含完整的拨弹测试模块。

## 配套固件与使用

建议使用本仓库 A/C/MC02 对应板型的 **1.26 固件**，各板固件不可混刷。EXE 不会自动更新或烧录固件；旧固件可能无法使用拨弹测试、板型识别等新增功能。

界面版本为 `UI 20261024-loader-control`。拨弹计数表示位置动作计数，并非实际出弹检测。

应用保持便携运行及未签名发布方式，内置串口依赖和网页资源。关闭窗口会请求全部停机并关闭串口，空格键可在页面处于焦点时急停。
