# MotorBench 上位机 v1.3.0

Windows 10/11 x64 单文件便携版，新增 ESP32-S3 Wi-Fi TCP 接入，并加入拨弹盘速度闭环防卡弹模式。

## 本次更新

- A 板默认通过 UART7 接入 ESP32-S3 Wi-Fi TCP 桥；桌面上位机连接桥接器热点即可复用原有 MotorBench 协议。C 板和 MC02 仍可使用 USB CDC。
- Wi-Fi TCP 连接带应用握手和自动重连；断线时控制板按心跳超时停机，恢复连接后不会自动重新使能。
- 增加拨弹盘模式：使能时自动采集实时稳态负载基准，之后监测卡弹并按实际角度小幅回退；提供卡弹次数及基于拨盘转角估算的卡弹率。
- 修正采样流程，支持回退超时和连续解卡上限均为 10 的设置；采样完成自动启动防卡弹，停止测试时结算末次角度并保留本轮统计。
- 拨弹盘模式使用累计角度遥测，三套控制板固件已更新至 1.27。

## 验证

已运行 TCP 传输、ESP32 UART 转发、拨弹盘控制与浏览器流程、HTTP 资源、界面引导、单双发位置测试、协议与电机状态回归；A/C/MC02 三套固件 Debug 编译通过。便携 EXE 通过中文路径、无外部 Node.js、资源加载、原生串口枚举、模拟 ESP32 TCP 握手与心跳、关闭窗口发送全停和后台退出检查。

本次完成软件模拟、编译与成品检查，未进行真实 ESP32 无线链路和拨弹台架验证。拨弹盘模式需要对应控制板固件至少为 1.27，EXE 不会自动烧录控制板。连接步骤见仓库中的 `esp32s3_wifi_bridge/README.md`。
