# MotorBench 上位机 v1.2.1

Windows 10/11 x64 单文件便携版，修复开始接收遥测、绘制波形后，图表持续变高并把旁边组件一起撑长的问题。

下载 `MotorBench-1.2.1-Windows-x64.exe` 后双击使用，无需安装 Node.js；可使用随附 `SHA256SUMS.txt` 校验文件完整性。

## 本次修复

- 绘图区独立参与页面布局，避免 Canvas 内部像素尺寸反过来撑大网格和相邻控件。
- 图表继续随相邻配置内容调整高度，展开、收起帮助内容后均能正常恢复布局。
- 更新界面标识为 `UI 20261025-chart-layout`；浏览器版更新源码后按 `Ctrl+F5` 刷新。

本次为上位机界面补丁，无需为此修复重新烧录固件。沿用 v1.2.0 的多开发板、曲线游标及单发/双发拨弹测试功能，桌面包保持便携、未签名发布方式。

## 发布验证

- 协议自检、HTTP 资源及界面版本检查。
- 使用实际通道模板持续绘制波形，验证单通道、多通道、窄窗口、1 / 1.25 / 2 倍设备像素比例，以及帮助内容展开、收起时的布局稳定性。
- 曲线游标、滤波、交点读数及模拟控制板页面引导回归。
- 新版便携 EXE 验证：中文/空格路径、无外部 Node.js、网页资源、原生串口枚举、渲染沙箱及关闭窗口后后台退出。

以上为软件回归和成品验证，本次发布未补充真实电机通电测试。
