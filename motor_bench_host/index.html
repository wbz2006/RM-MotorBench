ID 冲突提示:6020 的反馈 ID 是 0x204+ID(0x205~0x20C), 3508/2006 是 0x200+ID(0x201~0x208),两段区间重叠。 所以 6020 不能与 3508/2006 挂在同一条总线上 —— 例如 6020 用 ID1 会和 3508 用 ID5 撞车。建议:CAN1 只接 6020,CAN2 接 3508/2006。 每条总线最多挂 14 颗(受 CAN 过滤器数量限制)。

安全说明:电机在固件中预先登记,上位机只能选择清单内的电机。 未使能前电机不出力;约 1 秒收不到上位机心跳,A 板会自动全停; 关闭本页面或按 Ctrl+C 退出服务时也会下发全停。
