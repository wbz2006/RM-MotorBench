# 网页 PID 参数记忆

用户要求网页记住上次调试的 Kp、Ki,不再在刷新或绑定时总是恢复 20、1。

在当前浏览器的 localStorage 保存编辑值,键由电机型号、CAN 总线、ID 与 PID 环组成,不依赖会复用的通道号或清单索引。默认保存整组 PID(Kp、Ki、Kd、输出限幅、积分限幅),各电机和各环互不覆盖。输入有效非负数后自动保存;空值、非法值不覆盖最后有效记录。未保存过时仍用型号默认值。

初始化、绑定、刷新与重新添加通道时恢复记录。读回板端值仅用于查看,不覆盖上次手工调试值;“恢复该型号默认值”覆盖该电机当前环的记录。恢复网页数值不自动下发,仍通过“应用到电机”生效。浏览器存储不可用或数据损坏时页面继续工作并使用默认值。

先在真实浏览器和模拟板端应答中复现重置行为,再实现恢复和自动保存,验证刷新、切换电机/环、重新添加通道、恢复默认值、板端读回不覆盖记忆、无效输入与存储不可用。随后复跑解绑、波形及协议自测。
