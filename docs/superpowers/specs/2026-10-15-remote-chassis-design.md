# 遥控四轮底盘

用户明确要求麦克纳姆轮和全向轮底盘控制逻辑,取代把一个摇杆直接赋给四个电机的方案。

- 保留网页控制和原有单电机遥控;增加麦克纳姆、四轮 X 型全向模式。轮序固定为左前 FL、右前 FR、左后 RL、右后 RR,网页可选择四个不重复的通道和逐轮反向。
- 右摇杆上下为前后、左右为横移;左摇杆左右为旋转。坐标为前方 x 正、左方 y 正、逆时针 yaw 正。原始 DR16 横轴向右为正,在解算中取反。
- 采用归一化底盘指令,最大值为轮电机转子 rpm,不宣称底盘 m/s。麦轮使用 X 型辊子布局;全向轮为四轮 45 度 X 型切向布局。输出整体等比例缩放,最大绝对值不超过所设轮电机转速。方向按安装用逐轮反向修正。
- 四轮需同型号 DJI 电机、实际绑定速度环,通道独立且有效;最大转速遵守型号上限。不同单位/减速比不混用。
- 右拨杆上档、三个控制轴回中后允许显式整组使能。组内四轮同时启停;部分使能、遥控掉线、非法轴值、拨杆离开上档、USB 心跳超时、急停、切换模式、解绑组内任一轮均使整组停机。恢复不自动使能。
- 修改任一底盘成员 PID 时整组停机。组使能即时重新读取原子遥控快照并检查三轴中位,不只依赖上一周期 ready。网页配置编辑中、待确认或被拒后禁用所有启动入口,已有运行电机仍可停机。
- 原有 0x0D 六字节请求和 0x8E 十二字节报告保留。底盘请求 0x0D 十字节:source(2麦轮/3全向),四通道,反向位掩码,float32最大rpm。新增 0x0E 一字节整组使能请求。底盘 0x8E 报告在原12字节后追加四通道、反向掩码、int16横移轴、int16旋转轴,共21字节。
- A/C 固件保持同一策略实现,接收机读取在原有临界区中一次快照三轴。仅修改测试台路径,不启用框架的旧底盘任务,不操作实物烧录。

验证:纯 C 解算表、协议字节、真实 A/C 模块四电机行为、浏览器配置和整组启停、既有波形/解绑/控制回归,最后编译两板固件。缺少 Git 元数据,保留修改前副本供审查。
