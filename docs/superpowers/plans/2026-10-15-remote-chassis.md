# 遥控底盘 Implementation Plan

**Goal:** 用右摇杆平移和左摇杆旋转,经麦轮/全向轮解算同时控制四个电机。

**Architecture:** 纯 C bench_control 实现运动学和中位门控;motor_bench 处理协议和整组输出;网页配置轮序/反向并等待板端确认。

**Tech Stack:** C11, STM32 GCC, ES modules, Node native/C tests, Playwright。

- [x] 先补纯 C 方向/混控/限幅/门控用例和 JS 协议用例,确认失败。
- [x] 同步实现 A/C 策略、三轴读取、原子组使能、遥测配置和失联停机;真实四电机模块回归。
- [x] 网页增加两种底盘模式、四轮通道/反向、组使能/停机,连接协议并保留单电机模式。
- [x] 浏览器回归四轮配置与停止、非法/旧固件处理;回归波形、解绑、单电机遥控。
- [x] 原生测试和 A/C 完整固件编译,只读代码审查后交付,说明需重刷固件。

验证完成:协议自测、A/C 纯 C 旧单电机/新底盘策略、实际四电机固件模块、7项波形历史测试、8组底盘浏览器测试、7组解绑浏览器测试、9组波形浏览器测试及原有网页/单电机遥控浏览器回归均通过。桌面和390px窄屏已检查。

只读审查发现并修复了三处启动/停机边界,每处补充回归并观察修复前失败、修复后通过:运行中改 PID 整组停机;使能时读取即时中位;编辑/等待/拒绝配置时锁定全部启动入口。最终审查无遗留 Critical/Important。

两板 `mingw32-make -j4 all` 返回0,生成 build/basic_framework_ATYPE.hex 与 build/basic_framework_CTYPE.hex。保留工程原有 newlib syscall/RWX 链接警告,未修改链接配置。未烧录开发板或驱动实体底盘;浏览器使用模拟板端应答,原生测试执行生产 C 模块并替换硬件I/O。
